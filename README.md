# Kanji Notebook

A personal study app for the 3,000 kanji of *Remembering the Kanji* Books 1 and 3, with stories, a writing pad, spaced review, sound groups and common words. Works offline once opened.

Data sources: KANJIDIC2 and JMdict (EDRDG, CC BY-SA 4.0); stroke order from KanjiVG by Ulrich Apel (CC BY-SA 3.0). Kanji order follows the books' frame numbers.
